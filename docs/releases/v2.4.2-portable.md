# v2.4.2 免安装版：增强代理与 WebSocket 连接修复

下载 `LaunchDeck.exe`，双击运行。此版专注增强代理，不需要安装向导，也不需要勾选增强代理。

## 更新内容

- **修复 WebSocket 代理遗漏**：启动时明确传入 `WS_PROXY`、`WSS_PROXY`，与选定的 HTTP/HTTPS 代理保持一致，启动完成后恢复原来的用户环境设置。
- **补齐新版 Codex 后台进程的代理覆盖**：除界面和浏览器辅助进程外，也覆盖新版复制到用户目录的 Codex 后台程序。仅接纳路径受限、与当前官方安装包文件哈希一致的程序，并由受保护的代理宿主再次校验。
- **修复启动误报进程已退出**：Windows 可能返回短暂存在的启动转交进程；现在等待并核实真正启动的应用主窗口，保持通过注册应用入口启动。
- **避免意外停止增强代理**：应用已启动后，辅助步骤失败不会直接断开它的代理。关闭启动器窗口改为收至托盘继续运行；右键托盘图标选择“退出并停止增强代理”才会结束代理。
- **持续维护浏览器代理转发配置**：处理应用重新生成工具配置时遗漏代理转发名称的情况，保留备份、路径检查和并发写入保护。
- **精简便携版**：移除主题选项、主题商店、恢复外观按钮、主题执行代码和内置主题包。固定使用增强代理，保留主机、端口、启动、浏览器修复和中英文切换；不需要 Node.js/npx。

## 使用方法

1. 完全退出旧启动器和 ChatGPT / Codex。
2. 双击新版 `LaunchDeck.exe`，确认本地代理主机和 HTTP / Mixed 端口。
3. 点击“启动 ChatGPT / Codex”，按 Windows 和代理组件提示完成授权。
4. 关闭启动器窗口会收至托盘。需要停止代理时，使用托盘右键菜单。

仍为单 EXE 免安装版。首次准备受保护的组件缓存、启动驱动时需要 Windows 授权；不创建安装向导、开机启动项，不修改系统代理、DNS、FlClash 或 TUN，不修改客户端 ASAR / JS。
