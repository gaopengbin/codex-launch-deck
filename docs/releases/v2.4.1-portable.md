# v2.4.1 免安装版：新版 Codex 浏览器兼容与响应速度修复

下载 **LaunchDeck.exe**，双击即可使用，无需安装向导。此次推荐免安装版；增强代理首次使用时仍需 Windows 管理员授权准备受保护组件，每次启用需确认驱动与流量范围。

## 修复内容

- 适配 Codex Windows 包 `26.1013.3656.0` / 浏览器组件 `26.1013.31256`。
- 保留 Windows 应用包身份启动方式，避免更新后直接运行程序导致“该进程没有程序包标识符”。
- 浏览器兼容策略随应用启动传入，避免应用重建工具配置后失效；普通读取入口使用现有 DOM/截图路径。
- 增强代理增加 Codex 官方浏览器辅助程序的精确路径规则，修复内容读取前请求直连、反复等待约 21 秒的问题。辅助程序必须与当前注册安装包中的原件哈希一致。
- 原生 TLS 转发通过代理解析受支持的 ClientHello 主机名，避免使用异常的本地解析结果。
- 单 EXE 内置所需组件、校验清单、许可证和对应原生源码，校验后解包至本地缓存；原有版本可保留。

## 使用方法

1. 正常退出旧启动器及 ChatGPT/Codex。
2. 双击 `LaunchDeck.exe`，填写本地代理地址与端口。
3. 保持“增强代理”开启，按 Windows 提示授权并启动客户端。浏览器辅助程序的网络修复依赖此模式。

不需要安装向导，不修改系统代理、系统 DNS、FlClash 或客户端 ASAR，不关闭浏览器检查。增强模式会保留本地组件缓存，并非零文件落地。
