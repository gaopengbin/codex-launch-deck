# v2.4.3 免安装版：增强代理、精简界面与卡顿修复

下载 `LaunchDeck.exe`，双击运行。便携版固定使用增强代理，无需勾选，不包含主题功能和主题包，也不需要 Node.js/npx。

## 修复内容

- 补齐 WebSocket 的 `WS_PROXY`、`WSS_PROXY` 设置，以及与当前官方安装包哈希一致的 Codex 后台进程代理覆盖。
- 修复 Windows 启动转交进程提前退出导致的误报；继续使用注册应用入口启动，保持应用包身份。
- 修复辅助步骤失败或关闭启动器窗口时意外停止代理的问题。关闭窗口会收至托盘，右键选择“退出并停止增强代理”才结束会话。
- 将耗时检查及启动辅助程序等待移到后台，避免这些等待堵住启动器界面；同时读取标准输出和错误输出，避免管道互相等待。
- Windows 应用包查询增加 15 秒超时；超时仅停止启动器自己创建的查询进程，不结束 ChatGPT / Codex。
- 新增启动阶段、界面心跳延迟、内存与句柄数量诊断日志，保存在 `%LOCALAPPDATA%\LaunchDeck\Diagnostics`。每个日志最多 1 MiB，保留现有证据，最多创建八次会话日志；不记录请求正文、代理目标或凭据。
- 保留浏览器检查/修复及配置转发维护，移除主题选择、主题商店、恢复外观和主题启动逻辑。

## 使用方法

1. 完全退出旧启动器和 ChatGPT / Codex。
2. 双击 `LaunchDeck.exe`，确认本地代理的主机、HTTP / Mixed 端口。
3. 点击“启动 ChatGPT / Codex”，完成 Windows 和代理组件授权。
4. 关闭启动器窗口后代理仍在托盘运行；停止时使用托盘右键菜单。

这是单 EXE 免安装版，不需要安装向导。首次准备受保护的组件缓存及启用驱动仍需要 Windows 授权。不修改系统代理、DNS、FlClash 或 TUN，不修改客户端 ASAR / JS。

## 验证与边界

发布工作流检查代理规则及回滚、原生组件生命周期、TLS 转发、浏览器配置、应用包启动交接、免安装校验和托盘行为。界面回归测试使用会填满错误输出管道并延迟退出的受控辅助程序，验证等待不会堵住调用线程，并验证卡顿诊断能写入文件。

实机曾验证模型 WebSocket 恢复连接；随后也出现过上游核心重启附近的断线。此版本修复已确认的启动器问题，不承诺消除代理节点故障、上游网络中断或所有客户端重连。v2rayN 的日志保存需在其自身设置中开启，不会由启动器修改。
